# AI-ONE
منصة عربية RTL قابلة للتثبيت كتطبيق PWA ومتصلة بمشروع Supabase مستقل.

## النشر
فعّل GitHub Pages من Settings → Pages واختر الفرع main ومجلد الجذر. افتح رابط Pages في Safari على iPhone ثم Share → Add to Home Screen.

## الوظائف الحالية
- Supabase Auth بالبريد وكلمة المرور.
- حفظ المحادثات والرسائل وفق سياسات RLS.
- استدعاء Edge Function ai-router باستخدام جلسة المستخدم.
- مركز أدوات موحد في tool-hub.html يضم روابط الخدمات الرسمية والأدوات الداخلية.
- استوديو تحويل المقالات إلى صور.
- مكتب AI-ONE Company لإدارة المهام.

## حدود التكامل
مركز الأدوات الحالي هو بوابة موحدة وروابط رسمية، وليس ربط API شاملاً لكل خدمة خارجية. يجب ضبط مفاتيح مزودي AI داخل Edge Function Secrets. لا توجد مفاتيح مزودي AI في المتصفح. أي تكامل API إضافي يجب تنفيذه على الخادم مع حماية المفاتيح واختبار صلاحياته.

## ملاحظات
قد يتطلب التسجيل تأكيد البريد الإلكتروني. النسخة الحالية من المساعد تدعم النص؛ الصور والصوت والملفات تحتاج مراحل تكامل منفصلة.
