# AI-ONE
منصة عربية RTL قابلة للتثبيت كتطبيق PWA ومتصلة بمشروع Supabase.

## النشر
فعّل GitHub Pages من Settings → Pages واختر الفرع main ومجلد الجذر. على iPhone افتح الموقع في Safari ثم Share → Add to Home Screen.

## الوظائف
- Supabase Auth بالبريد وكلمة المرور.
- حفظ المحادثات والرسائل وفق سياسات RLS.
- Edge Function باسم `ai-router` لتوجيه الطلبات إلى مزودي الذكاء الاصطناعي المتاحين.
- أوضاع للمهمة: تلقائي، تفكير وتحليل، برمجة، بحث، وإبداع ومحتوى.
- ترتيب مزودي النماذج بحسب نوع المهمة مع الانتقال تلقائياً إلى مزود بديل عند الفشل.
- دعم مفاتيح الخادم الاختيارية: `GROQ_API_KEY`, `GEMINI_API_KEY`, `OPENROUTER_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`.
- مركز الأدوات الموحد في `tool-hub.html` لفتح الخدمات الرسمية والأدوات الداخلية.
- استوديو المقالات إلى صور في `article-studio.html`.
- مكتب AI-ONE Company في `company.html`.

## إعداد مزودي النماذج
أضف مفاتيح المزودين في Supabase → Edge Functions → Secrets فقط. لا تضع أي مفتاح في ملفات الواجهة أو GitHub. يمكن ضبط أسماء النماذج عبر:
- `GROQ_MODEL`
- `GEMINI_MODEL`
- `OPENROUTER_MODEL`
- `ANTHROPIC_MODEL`
- `OPENAI_MODEL`

يعمل التوجيه فقط للمزود الذي تم إعداد مفتاحه. ترتيب الأولوية يتغير حسب المهمة، وتظل المفاتيح على الخادم. الخدمات الخارجية في مركز الأدوات تظل روابط مستقلة ما لم يُنفذ تكامل API رسمي لها.

## حدود النسخة الحالية
المساعد يدعم المحادثة النصية. توليد الصور والفيديو والصوت ورفع الملفات وربط خدمات مثل n8n وMCP مباشرة داخل المحادثة مراحل مستقلة تحتاج تكاملات وخوادم ومفاتيح مناسبة. لا يعني ظهور خدمة في مركز الأدوات أنها متصلة تلقائياً.

قد يتطلب التسجيل تأكيد البريد الإلكتروني.
